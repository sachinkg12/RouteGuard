Know when not to answer.

RouteGuard measures whether a classifier should auto-decide or defer an uncertain item to a human, when a wrong auto-decision costs far more than a deferral. It reports calibration, coverage, and expected cost, not just accuracy.

02 · The cost problem

Accuracy hides the expensive mistakes.

Two systems with the same accuracy are not equally good if one makes its errors on decisions that are costly to reverse. RouteGuard scores the decision, not just the label, under an asymmetric cost model.

E[cost]
=
(1 − coverage)deferred → human triage, cost 1 + coverage × (1 − routed acc) × 5auto-routed but wrong, cost 5 + 0auto-routed and correct, cost 0

Coverage is the share of items auto-routed; the rest are deferred. Raising the confidence threshold defers more, lowering wrong-route rate but paying more triage. The cost model finds the balance.

03 · How it works

A pipeline that separates every concern.

Prediction, confidence, abstention, and cost are independent stages. The evaluator never inspects a predictor's internals, so a new model or policy plugs in without touching it.

Predictorlabel + score
Confidencecalibrate the score
Abstentionroute or defer

Evaluatortables + figures
Predictors

Classical & LLM

TF-IDF (LR / SVM / RF), fine-tuned DistilBERT, and prompted LLMs share one interface.

Confidence

Calibrated scores

Model-reported, cross-predictor agreement, or isotonic recalibration fit on a held-out split.

Abstention

Threshold policies

Route above a confidence threshold; defer below it. Always-route is the baseline.

Cost

Asymmetric & swept

Configurable (c_ok, c_triage, c_wrong), evaluated across a grid so conclusions are not tied to one setting.

05 · Findings

What the framework measured

On a public 47,837-ticket support dataset (8 classes, 70/10/20 split). Cost model (c_ok, c_triage, c_wrong) = (0, 1, 5).

38.1%lower expected cost than always-routing (best classical baseline)
0.863best classical accuracy (Linear SVM)
95.0%routed accuracy at the chosen threshold
70.5%coverage (share auto-routed)
3.5%wrong-route rate
≥86%ECE reduction from isotonic recalibration

Cost reductions range 35.5–38.1% across the four non-LLM baselines (TF-IDF+LR, Linear SVM, Random Forest, DistilBERT). Numbers describe this dataset under the stated cost model; they are not a claim of general or production performance.

06 · Reproduce

One synthetic run needs no data or keys.

The default client is a no-op mock; nothing calls an external API unless a config opts in. Every run snapshots its config, seeds, dataset hash, and package versions.

1

Install

pip install -e '.[test]'
2

Smoke run

python scripts/run_classification.py --config configs/experiment_small_debug.yaml
3

Test

pytest
4

Inspect

ls outputs/<run>/paper_bundle/
headline classical run (no API calls)
# place the public CSV at data/it_service_tickets.csv, then:
python scripts/prepare_data.py    --config configs/experiment_default.yaml
python scripts/run_classification.py --config configs/experiment_default.yaml

# rebuild the cost sweep from a saved run, no re-prediction:
python scripts/run_cost_analysis.py --run-dir outputs/<run>

The dataset is not redistributed

It is public and governed by its own terms. Download it, place the CSV, and the loader reproduces the stratified split from seed 42. A bundled synthetic generator covers tests and smoke runs.

08 · Limitations

What this does not claim.

One corpus

Results are measured on a single public dataset; they do not establish general performance across ticket queues.

Illustrative costs

The (0, 1, 5) model is a stand-in. Real deployments require organization-specific cost tuning; the grid sweep shows sensitivity.

No deployment

This is an offline evaluation framework, not a live service or human user study.

Model drift

LLM numbers depend on model version and prompt wording; fixed names do not freeze a hosted service.
